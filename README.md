# ВУС бот (@vus_ua_bot) — этап 1

Что умеет: выбор языка (UA / RU / EN), главное меню, подача объявления в 9 шагов, ручная модерация в закрытом канале админов, публикация в канал @vus_ua, «Мои объявления» (продление и удаление), напоминание за 2 дня и автоматическое снятие объявления через 30 дней.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `src/index.js` | вся логика бота |
| `src/i18n.js` | тексты на трёх языках — можно править без программиста |
| `src/data.js` | страны, города, рубрики |
| `src/tg.js` | работа с Telegram API |
| `schema.sql` | таблицы базы данных |
| `wrangler.toml` | настройки Worker |

## Запуск — по шагам

**1. GitHub.** Создай репозиторий `vus-bot` → «Add file» → «Upload files» → перетащи все файлы и папку `src` → «Commit changes».

**2. База данных.** Cloudflare → Workers & Pages → D1 → «Create database» → имя `vus-db`. Открой базу → вкладка «Console» → вставь всё содержимое `schema.sql` → «Execute». Скопируй **Database ID** базы.

**3. Узнай два ID:**
- твой Telegram ID — напиши боту @userinfobot;
- ID закрытого канала «ВУС | Адмінка» — перешли любое сообщение из него боту @userinfobot (число вида `-100…`). Ещё способ: открой канал в web.telegram.org — число `-100…` будет в адресной строке.

**4. Заполни `wrangler.toml`** прямо на GitHub (иконка карандаша): `database_id`, `ADMIN_CHAT_ID`, `OWNER_ID`. Если юзернеймы канала или группы у тебя другие — поправь их тоже.

**5. Worker.** Cloudflare → Workers & Pages → «Create» → «Import a repository» → выбери `vus-bot` → «Deploy».

**6. Секреты.** Worker → Settings → Variables and Secrets → добавь два значения типа **Secret**:
- `BOT_TOKEN` — токен бота из @BotFather;
- `WEBHOOK_SECRET` — любой длинный пароль из латинских букв и цифр (например, `vus2026SuperSecretKey`).

**7. Права бота.**
- канал @vus_ua: добавить бота администратором с правами «Публикация», «Редактирование», «Удаление сообщений»;
- канал «ВУС | Адмінка»: администратор с правами «Публикация» и «Редактирование».

**8. Подключи бота.** Открой в браузере:
`https://vus-bot.<твой-поддомен>.workers.dev/register?key=<WEBHOOK_SECRET>`
Должно появиться `"ok": true`. Важно: после этого старый падел-Worker перестанет получать сообщения этого бота — так и нужно.

**9. Проверь.** Напиши боту /start → выбери язык → «Подати оголошення» → пройди шаги → в «ВУС | Адмінка» появится карточка → нажми «Опублікувати» → пост появится в @vus_ua.

## Если что-то не работает

Worker → вкладка «Logs» → «Begin log stream», затем снова напиши боту. Строки `TG ... failed` объясняют причину (чаще всего — не хватает прав бота в канале или неверный `ADMIN_CHAT_ID`).
